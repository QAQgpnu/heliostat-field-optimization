# Derived data

This directory contains small public derivatives from retained team-result workbooks. It does not contain the original Excel files.

- `result2_sample.csv`: 96 evenly spaced retained rows from the uniform-size layout;
- `result3_sample.csv`: 96 evenly spaced retained rows from the variable-size layout;
- `layout_comparison_summary.csv`: aggregate statistics calculated from all 1,752 retained records in each workbook;
- `derivation_manifest.json`: sampling rule and publication boundary.

Values in sample rows are unmodified except for normalized column names. These data are provided for review and historical comparison, not as a validated optimal field or a standalone benchmark. The MIT license applies to reconstruction code; it does not assert exclusive ownership of the underlying team-result data.
