# Contributing

1. Open an issue describing the formula, assumption, or data-quality change.
2. Keep original contest materials and third-party datasets out of commits.
3. Add or update tests for numerical changes.
4. Run `python -m pytest`, `ruff check .`, and the demo before opening a pull request.
5. State whether a result is analytical, simulated, reconstructed, or measured.

Exact ray-tracing contributions are welcome when their geometry, error model, validation data, and computational cost are documented.
